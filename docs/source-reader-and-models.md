# 源码阅读与大模型解释

左侧品牌说明为“二进制静态分析工具”。版本信息仍可在系统维护的运行状态中查看。

左侧导航将“新建任务”作为主操作，其他入口按工作区和系统管理分组。底部头像菜单提供修改密码与退出登录，收起导航后仍可打开。桌面展开／收起偏好保存在当前浏览器；专注阅读会临时收起主导航，退出后恢复之前的偏好。

## 阅读源码

同一任务内选择源码文件只更新当前文件和地址栏，不将页面滚回顶部。编辑器、加载态与错误态使用固定的工作区域。每个任务／项目／文件分别保存滚动位置、光标和折叠状态；首次打开文件从开头显示，返回已读文件恢复原位置。漏洞详情等明确的行号定位优先于历史位置。浏览器前进、后退及复制源码定位链接继续可用。

源码工作台提供专注阅读、AI 解释和文件查找；编辑器提供查找、跳行与复制。`Ctrl/Cmd+P` 聚焦源码文件搜索，`Ctrl/Cmd+G` 打开跳行。专注阅读会铺满可用区域，隐藏页面滚动；退出按钮或 Esc 恢复原页面位置。分析操作和引擎／诊断信息可分别展开，不再占据多层常驻说明区域。

目录顶部可以搜索、切换源码项目，并按能力筛选；文件按真实目录展开／收起。搜索会展开匹配路径，清除后恢复手动展开状态。“定位当前文件”只滚动目录内部；目录支持上下左右、Home/End、Enter。大量文件分批渲染，可继续显示，搜索始终覆盖完整清单。

打开的文件显示为页签，同名文件的完整路径与项目可通过悬浮提示区分；跨项目切换仍保留文件阅读位置。页签支持左右、Home/End 切换与 Delete 关闭，当前唯一页签保留。面包屑可定位目录，旁边按钮复制完整路径。目录和代码分别滚动；分隔线可拖动，也可聚焦后用左右方向键调整，Shift 加大步长，Home/End 调到边界。目录宽度会保存在当前浏览器中，不保存源码内容。复制可选择附带文件名、行号。

## 配置模型

管理员打开“系统维护 → 大模型设置”，选择服务提供商并填写接口地址、模型名称、API Key。默认提供商为 DeepSeek，根地址 `https://api.deepseek.com`，模型 `deepseek-flash`；兼容服务可使用根地址或 `/v1` 地址。模型名可按实际账号支持的型号调整。关闭功能时不会发出模型解释请求。

先保存设置，再点击“测试连接”。测试只发送固定连通性语句，不发送项目源码。接口超时、输入字符数、输出 Token 数和并发上限均可配置。空白 Key 输入保留已有 Key；勾选“清除已保存的 Key”后保存才会清除。

配置位于 App 挂载的存储根目录 `.settings/` 中。API Key 使用 AES-GCM 加密，后端密钥文件与配置文件分别保存，权限限制为服务用户可读写；浏览器只会取得掩码。备份 App 存储时应一并保护并保留该目录。接口与日志不回传 Key，Key 不写入浏览器本地存储或镜像。

离线客户可以关闭此功能，或将地址改为可访问的内网兼容模型服务；原有反编译、检测与报告功能不依赖模型服务。修改运行目录中的模型配置无需重新构建镜像。

## 使用解释

在反编译源码工具栏打开“AI 解释”，选择解释当前文件或所选行。发起前核对提供商、接收地址、文件、行号、字符数和预览，再主动提交；系统不会因浏览文件自动上传代码，也不会自动上传整个项目。超过输入上限时应改为较小选区。

解释会逐步显示，可停止、重试、复制或点击行号回到对应源码。系统保存文件、源码 SHA-256、范围、模型、时间与生成状态；同一版本及范围的已完成解释可直接复用。需要重新调用模型时使用重新生成。停止后保留已经收到的部分文本及取消状态；上游可能已经产生的用量由模型服务自行计费。

空间足够时，解释与源码并排展示，代码区域至少保留 420 像素。可拖动解释面板左边缘或聚焦分隔线后用左右键调整宽度，Home/End 调到边界；宽度偏好仅保存在当前浏览器。空间不足时通过“代码／AI 解释”页签切换，切到代码不会停止正在生成的解释。关闭解释面板会停止生成。切换文件默认回到“当前文件”，避免沿用上一文件的选区。

历史记录随源码文件显示，源码改变后旧记录标记为过期。切换文件不会将上一文件的解释显示为当前文件的结果。管理员与操作员可以发起解释，只读用户可以阅读已有结果。模型输出是辅助说明，反编译产生的变量名、类型和控制流可能不完整，不确定的结论应结合实际代码行为验证。

并发控制与中断恢复适用于当前单 App 实例部署。App 启动时会将上次进程遗留的“生成中”记录标记为失败，保留已持久化的内容；用户可重新发起解释。

## 验证

前端使用 `npm test` 与 `npm run build`；后端使用 `go test ./internal/llm ./internal/app`。项目内提供 `script/tests/llm-integration.py` 和配套本地兼容服务，验证真实 App、MySQL、配置持久化、权限、源码身份、SSE、缓存、取消、超时和限流。它仅使用已有本地镜像、带归属标签的临时容器、独立数据库与 `.cache/llm-integration` 中的示例源码，不连接付费模型服务，也不更改现有用户或业务数据。

```powershell
python script/tests/llm-integration.py setup
python script/tests/llm-integration.py check
python script/tests/llm-integration.py cleanup
```

部署更新后应保留现有 `.env` 和 `data/`，只更新所需的 App 镜像及交付清单；不要用重新打包或重置数据来替代服务更新。
